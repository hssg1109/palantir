요청하신 내용을 반영하여, 점검 프로세스를 간소화하고 서버 장애 방지 대책을 구체적인 수치로 명시하여 다듬은 가이드입니다.

**대량 스크립트 실행(API 진단) 절차 및 서버 장애 방지 대책**

본 가이드는 고객사 서비스를 대상으로 대량의 스크립트(API Fuzzing, Scanning 등)를 실행할 때 준수해야 할 표준 절차와 서버 가용성 확보를 위한 구체적인 임계치 설정을 정의합니다.

## **1\. 진단 환경 및 사전 협의 원칙**

**※ 동적분석(Dynamic Analysis)은 ‘개발기(Staging/Dev)’ 진행을 원칙으로 합니다.**

* **상용기(Production) 진단 예외 절차:** 아래 Case에 해당할 경우, 반드시 보안진단 담당자와 상용기 수행에 대한 별도 협의가 필요합니다.  
  * 개발/알파/스테이징 서버가 존재하지 않는 경우  
  * 담당자 요청에 의해 상용기 진단이 불가피한 경우  
* **관리자 웹페이지 진단 시 필수 사항:**  
  * **개발기 진단 필수:** 관리자 기능의 특성상 데이터 삭제 및 변경 위험이 높음  
  * **주의 기능 목록 확보:** 진단 전 Push 알람, 전체 공지 문자 발송 등 대량 전파 기능 파악

## ---

**2\. 스캐닝 및 점검 프로세스**

기존의 협의 단계를 통합하여 효율적으로 커뮤니케이션합니다.

1. **진단 준비:** 자산 요청 이후 점검 도구 설정 및 계정 생성 등 필요한 준비를 완료합니다.  
2. **일정 통보 및 확인 요청:**  
   * 별도의 \*\*\[스캐닝/스크립트 실행 알림 양식\]\*\*을 사용하여 개발자 및 담당자에게 메일을 발송합니다.  
   * 메일 내용 포함 사항: **진단 대상(URL/IP), 예상 포트 스캔 일정, 대량 API 요청 발생 가능 시간대**  
   * 이 단계에서 담당자에게 운영계 점검 불가 여부 및 개발계 가용 여부를 한 번에 회신받습니다.  
3. **최종 확인 및 수행:**  
   * 담당자 회신(승인) 확인 후 즉시 진단을 수행합니다.  
   * **운영기 점검 시:** 스캔 **시작 시점**과 **종료 시점**에 담당자에게 알림(메신저 또는 메일)을 발송하여 모니터링을 지원합니다.

## ---

**3\. 서버 에러 및 서비스 장애 방지 대책 (구체적 설정값)**

대량 요청으로 인한 가용성 침해(DoS) 및 데이터 오염을 방지하기 위해 툴(Burp Suite, Scanner 등) 설정 시 아래 **임계치를 강제 적용**합니다.

### **가. 요청 속도 및 동시성 제어 (Throttling)**

운영 환경에 부하를 주지 않도록 물리적인 요청 속도를 제한합니다.

* **쓰레드(Concurrent Requests) 제한:**  
  * **개발기:** 최대 **5개** 이하  
  * **운영기:** 최대 **1\~2개** (Single Thread 권장)  
* **지연 시간(Delay) 설정:**  
  * 요청과 요청 사이에 최소 **500ms \~ 1,000ms (1초)** 이상의 지연 시간 설정  
  * 랜덤 지연(Jitter) 기능을 활성화하여 패턴 기반 차단 시스템(WAF) 과부하 방지

### **나. 비상 중단 정책 (Fail-safe)**

서버 응답 상태를 실시간으로 확인하며, 다음 조건 발생 시 **즉시 스크립트 실행을 중단**하고 담당자에게 상황을 공유합니다.

* **HTTP 500 (Internal Server Error) 발생 시:**  
  * 연속 **5회** 이상 발생 시 즉시 중단  
* **응답 지연(Time-out) 발생 시:**  
  * 평균 응답 속도가 \*\*5,000ms (5초)\*\*를 초과하는 현상이 **1분 이상 지속**될 경우 중단  
* **서비스 불능(HTTP 503\) 발생 시:**  
  * 단 **1회**라도 발생 시 즉시 중단 및 인프라 담당자 확인

### **다. 데이터 안전성 확보**

* **HTTP Method 제한:** 자동화 툴 사용 시 GET, OPTIONS, HEAD 메소드 위주로 수행하며, 데이터 변경을 유발하는 POST, PUT, DELETE는 자동 스캔 대상에서 제외하거나 수동 검증으로 대체합니다.
