## Gemini NotebookLM 용 프롬프트

```
첨부된 문서는 AI/LLM을 실제 보안 진단 업무에 적용한 사례 발표자료 원고입니다.

이 내용을 바탕으로 사내 AI 활용 사례 공유 세션용 PPT 슬라이드 구성안을 만들어주세요.

[요구사항]
- 슬라이드 수: 15~18장
- 청중: 보안 비전문가 포함한 사내 직원 전체
- 톤: 전문적이되 어렵지 않게, 실제 수치와 사례 중심
- 각 슬라이드마다: 제목 / 핵심 메시지 1줄 / 본문 내용(불릿 3~5개) / 발표자 노트

[슬라이드 구조]
1. 표지: "AI로 보안 진단을 자동화한 이야기"
2. 목차
3. 배경: 왜 AI가 필요했나 (기존 한계)
4. 무엇을 했나: AI 적용 3대 영역
5~6. Before: 수동 방식의 한계 (구체적 수치 포함)
7~8. After: AI 적용 후 변화 (Before/After 표 포함)
9. 실제 수치: 1,931건 → 248건, 31개 레포, 3주 완료
10~11. 산출물 소개: 자동 생성 보고서, Audit Log
12~13. 재사용 프롬프트: 교차검증 / 보고서 작성 / CVE 판단
14. 진단 기준 자기 갱신 (Audit 피드백 루프)
15. 한계와 주의사항 (솔직하게)
16. 마무리: "AI는 탐색하고 사람은 판단"

[디자인 가이드]
- 배경: 다크 네이비 또는 딥 블루 계열 
- 강조색: 시안(#00B4D8) 또는 라임 그린
- 코드/JSON 예시는 코드 블록으로 표시
- Before/After는 좌우 2분할 레이아웃
- 수치는 크게 강조 (폰트 크기 업)
```

## Claude 용 프롬프트

```
아래에 첨부한 문서는 AI/LLM을 보안 진단 업무에 실제 적용한 사례 발표자료 원고입니다.

이 내용을 바탕으로 PPT 슬라이드 스크립트를 작성해주세요.

[출력 형식]
각 슬라이드를 아래 형식으로 작성:

## 슬라이드 N: [제목]
**핵심 메시지**: (한 줄 요약)
**본문**:
- 불릿 1
- 불릿 2
- 불릿 3
**발표자 노트**: (말할 내용 2~3문장)
**시각 요소 제안**: (그래프, 표, 아이콘 등)

---

[주요 강조 포인트]
1. 수치로 말하기: 1,931건 → 248건, 31개 레포 3주, 오탐 27.4%
2. 역할 변화가 핵심: "탐색 → 판정"으로 담당자 역할 전환
3. 재사용성: 청중이 내일 바로 써먹을 수 있는 프롬프트 패턴 소개
4. 솔직함: AI의 한계도 반드시 포함 (신뢰도 확보)

[슬라이드 수]: 15~18장
[청중 수준]: 보안 전문가부터 비전문가까지 혼재
[발표 시간]: 20~25분
```

---

## 핵심 수치 레퍼런스 (슬라이드에 활용)

| 수치 | 의미 |
|---|---|
| **31개** | 진단 완료 레포 수 (OCB 서비스군) |
| **1,931건** | AI 스캐너가 탐지한 전체 후보 |
| **248건** | 최종 확정 Finding (LLM 교차검증 후) |
| **87%** | AI가 자동 처리한 비율 (1,931 중 1,683건은 양호/필터) |
| **27.4%** | 오탐률 (스캐너 후보 중 실제 취약이 아닌 비율) |
| **5개** | AI 판정 피드백이 공식 진단 기준으로 확정된 사례 수 |
| **2~4시간** | AI 도입 후 레포 1개 진단 소요 시간 |
| **5분** | 보고서 초안 자동 생성 시간 |
| **3주** | 31개 레포 전체 진단 완료 소요 시간 |

## 슬라이드 핵심 스토리라인

```
[문제 제기]
  → 31개 레포를 수동으로 하면 몇 달. 현실적으로 불가능

[해결책 소개]
  → AI가 1,931건을 스캔하고, 사람은 248건만 판정

[증거]
  → Before/After 수치, 실제 보고서 화면, Audit Log 예시

[재사용]
  → 이 4가지 프롬프트 패턴이면 누구나 시작 가능

[솔직한 한계]
  → AI는 실행 환경을 모른다. 최종 판단은 항상 사람이

[마무리]
  → AI는 탐색하고 사람은 판단. 이 분업이 핵심
```

## 이미지/시각화 아이디어

| 슬라이드 | 시각 요소 |
|---|---|
| Before/After | 좌(빨강): 수동 흐름도 / 우(초록): AI 자동화 흐름도 |
| 수치 | 원형 그래프: 1,931건 중 248건(정탐) 시각화 |
| 역할 변화 | 파이 차트 비교: 기존 탐색60%/분석30%/보고10% vs 현재 판정70%/기준개선30% |
| 피드백 루프 | 순환 화살표 다이어그램: 판정→누적→기준→자동적용→판정 |
| 프롬프트 패턴 | 코드 블록 스타일로 프롬프트 텍스트 표시 |
| 한계 | 경고 아이콘과 함께 5가지 한계 나열 |
